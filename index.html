About AtmosVue

AtmosVue aggregates public weather data into a single tracking board for the Philippines and the wider Western Pacific. It is built for general awareness only. It is not an official warning system, and forecasts — especially Philippines-specific ones, which depend on a manually updated data/ph-storms.json file — can lag or be wrong.

Sources

  • OpenStreetMap — basemap
  • RainViewer — precipitation radar tiles
  • Open-Meteo — ambient wind & pressure grid
  • GDACS — global tropical cyclone events
  • NOAA / NHC — Atlantic & Eastern Pacific storms, genesis outlook
  • PAGASA / JTWC — Philippine bulletins (via local JSON drop)

For watches, warnings and anything safety-critical, always consult pagasa.dost.gov.ph.
